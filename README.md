# smart-patrol-car-lab

This repository is organized into five functional modules for smart patrol car development.

## Modules

- `02-smart-car-platform-environment-perception` - Environment perception development for the smart car platform
- `03-lidar-slam-mapping-autonomous-navigation` - LiDAR SLAM mapping and autonomous navigation
- `04-lidar-tracking-obstacle-avoidance` - LiDAR-based tracking and obstacle avoidance
- `05-computer-vision-target-tracking` - Intelligent vehicle target tracking with computer vision
- `06-harmonyos-app-development` - HarmonyOS app development for the smart car platform

## Notes

Each folder is currently a placeholder for code, documents, and experiments related to its module.
